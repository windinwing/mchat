# 股票功能扩展：资金流向 / 超买指数 / 行业超买指数（申万1/2级行业）

## 背景与现状结论

| 需求 | 现状 | 本次做法 |
|---|---|---|
| 股票当天资金流向 | `stock-capital` 已有个股主力资金流（东财），无"板块/市场维度" | **新建 `stock-sector` skill**，补"今日行业资金净流入排行" |
| 股票超买指数 | `stock-quote` 只有单股 RSI 阈值 | **新建 `stock-overbought` skill**，单股综合 RSI/KDJ/BOLL → 0-100 超买度评分 |
| 行业超买指数（申万1/2级） | 完全缺失 | **并入 `stock-sector` skill**，基于申万行业指数 K 线算行业超买度 |

> 决策理由：资金流向(板块级) 与 行业超买(申万) 都是"行业/板块"维度，合并到一个 `stock-sector` skill 内聚更合理；个股超买度是"单股"维度，单独成 skill，可直接被现有"诊股"工作流当渠道接入。

akshare 接口已实测验证（1.18.80，装入 mchat/.venv）：
- 申万一级 `sw_index_first_info()`、二级 `sw_index_second_info()`、实时行情 `index_realtime_sw`、成分股 `index_component_sw`、行业指数K线 `index_hist_sw`
- 板块资金流 `stock_sector_fund_flow_rank(indicator="今日", sector_type="行业资金流")`
- ⚠️ 后两者依赖东方财富可达，skill 内做 try/except 友好降级

## 架构原则（沿用现有约定）
- **不改 `si_common`**：申万/资金流是"领域查询型"，不需要多数据源切换，新 skill 直接 `import akshare`（与 stock-search 处理概念板块一致）
- **复用现有指标**：`stock-quote/indicators.py` 的 `compute_all()` 直接算行业指数超买度（字段名映射 `收盘→close` 等）
- **标准信封**：用 `si_common.schema.make_envelope / signal` 输出，channel 取 `sector` / `overbought`
- **前端零改**：新 skill 通过 `SKILL.md` 的 `workflow_fields` 自动渲染参数表单；报告面板已能识别 `signals/stocks/top_gainers/board_avg_pct`

## 实施步骤

### 第 1 步：新建 skill `stock-overbought`（个股超买指数）

**目录**：`/Users/xiaoxiao/dev/skills/StockIntelligence/stock-overbought/`

文件：
1. **`SKILL.md`** — frontmatter
   - `name: stock-overbought`，`workflow_role: search`
   - `parameters`: `{code(required), days(default 120)}`
   - `workflow_fields`: code(text,required,placeholder 600519)、days(number,default 120)
   - `outputs`: ok/summary/overbought_score(0-100)/level(超买/超卖/中性)/signals/raw
   - metadata.openclaw.install: akshare, pandas
2. **`main.py`** — 三段式（参照 stock-search）
   - `collect(code, days=120) -> dict`：
     - 取日 K（`get_provider().daily_quotes(code, days)`）
     - 复用 `stock-quote/indicators.py` 的 `rsi()/kdj()/compute_all()`（import 兄弟目录）
     - 综合超买度算法（0-100，越高越超买）：
       - RSI 贡献：`rsi/100 * 40`（RSI 越高超买）
       - KDJ-J 贡献：`clip(j,0,100)/100 * 30`
       - BOLL 位置贡献：`(close-lower)/(upper-lower) * 30`（价格越靠上轨越超买）—— 需在 indicators.py 或本 skill 内补一个 `boll(df)` 函数
       - 加权求和 → 0-100
     - level 判定：≥70 超买(偏空)、≤30 超卖(偏多)、其余中性
   - `run(code, days=120, **kwargs) -> dict`：返回标准结构 + `make_envelope(channel="overbought", signals=[...], raw=指标快照, summary=MD)`
   - `main()`：CLI 入口 `python3 main.py 600519 --json`
3. **复制 `si_common/` 副本**（从 stock-search 复制，保持 mchat 部署一致）

### 第 2 步：新建 skill `stock-sector`（板块资金流 + 申万行业超买）

**目录**：`/Users/xiaoxiao/dev/skills/StockIntelligence/stock-sector/`

文件：
1. **`SKILL.md`** — frontmatter
   - `name: stock-sector`，`workflow_role: search`
   - `parameters`: `{mode(enum: fund_flow|overbought|both, default both), level(enum: 一级行业|二级行业, default 一级行业), top(default 10)}`
   - `outputs`: ok/summary/sectors(列表含 name/code/fund_net/overbought_score/change_pct)/top_inflow/top_overbought/signals
2. **`main.py`** — 三段式
   - `_collect_fund_flow(level, top) -> dict`：
     - `ak.stock_sector_fund_flow_rank(indicator="今日", sector_type="行业资金流")`
     - try/except 降级：EM 不可达时返回空 + error 提示
     - 输出字段映射：名称、今日主力净流入-净额、今日涨跌幅、今日主力净流入最大股
   - `_collect_sw_overbought(level, top) -> dict`：
     - `sw_index_first_info()` / `sw_index_second_info()` 拿行业清单（注意 `.SI` → 裸码归一化）
     - 对每个行业 `index_hist_sw(symbol=裸码, period="day")` 取近 120 日 → 字段映射 → `compute_all()` 算 RSI
     - 行业超买度 = 成分/指数的 RSI 综合分（复用 stock-overbought 的算法函数，提取为共享 helper）
     - 限制并发/数量（top 个），避免拉取过慢
   - `collect(mode, level, top)` → 调上述两者
   - `run(mode="both", level="一级行业", top=10, **kwargs)` → 标准信封 `channel="sector"`
3. **复制 `si_common/` 副本**

> 超买度算法在两个 skill 共用，方案：在 `stock-overbought/overbought.py` 定义 `overbought_score(rsi_val, kdj_j, boll_pos)` 纯函数，`stock-sector` 通过 sys.path import 复用（参照 si_common 跨 skill import 模式）。

## 风险与降级
- 东方财富接口（板块资金流）在生产环境须可达；skill 内 try/except，失败时返回 error 字段不阻断工作流
- 申万行业指数 K 线 `index_hist_sw` 无日期参数、拉全量，需客户端 `.tail(days)` 裁剪；行业数量多时限制 top 个避免超时
- 超买度算法为规则加权（非金融严谨模型），SKILL.md 会注明"仅供参考，不构成投资建议"
